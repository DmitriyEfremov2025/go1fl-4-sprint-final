# Модуль фитнес-трекера

## Мультфильмы про основы Go

В репозитории есть интерактивные мультфильмы со звуком:

- `cartoon/go-gopher-basics.html` — короткая вводная серия.
- `cartoon/go-gopher-series.html` — улучшенная версия с тремя сериями по 5 минут.

Чтобы посмотреть мультфильм, откройте HTML-файл в браузере и нажмите кнопку **«Старт со звуком»** или **«Включить мультик со звуком»**. Озвучка запускается после нажатия, потому что браузеры блокируют автоматическое воспроизведение звука без действия пользователя. В улучшенной версии фоном играет синтезированная public-domain тема Бетховена «Ода к радости».

Для записи серий можно открыть улучшенную версию с параметрами автостарта:

```text
cartoon/go-gopher-series.html?episode=1&autoplay=1
cartoon/go-gopher-series.html?episode=2&autoplay=1
cartoon/go-gopher-series.html?episode=3&autoplay=1
```

## Тестирование проекта

Рядом с файлами, которые вы будете редактировать, находятся файлы с суффиксом _test.go. В них содержатся юнит-тесты, проверяющие корректность вашей реализации. Эти тесты автоматически запускаются на GitHub. Чтобы работа была зачтена, ваш код должен успешно проходить все тесты. Обратите внимание: изменять содержимое тестов запрещено.

Вы можете запускать тесты локально, выполнив следующие команды в корневой директории репозитория:

```bash
go mod tidy
go test -v ./...
```
